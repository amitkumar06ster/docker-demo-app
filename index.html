This project demonstrates a fully automated DevOps CI/CD pipeline that enables continuous integration, automated containerization, and continuous deployment from source code commit to production deployment.

Every code change pushed to GitHub automatically triggers a Jenkins Pipeline, which validates the source code, builds a Docker image, publishes it to Docker Hub, and deploys the latest application version to AWS EC2 with minimal manual intervention.
