📌 Project Overview

This project showcases the successful implementation of a complete Continuous Integration and Continuous Deployment (CI/CD) pipeline using GitHub, Jenkins, Docker, Docker Hub, and an On-Premises Rocky Linux Server.

The objective of this project was to automate the software delivery process from source code management to production deployment, reducing manual effort and ensuring faster, reliable, and consistent releases.

Whenever developers push code changes to GitHub, Jenkins automatically triggers a pipeline that retrieves the latest source code, builds a Docker image, pushes the image to Docker Hub, and deploys the updated application to an on-premises Docker server.

This implementation demonstrates modern DevOps practices including automation, containerization, continuous integration, continuous deployment, and infrastructure management within a Linux-based environment.
